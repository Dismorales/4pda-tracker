# 4PDA Tracker

4PDA Tracker — локальное расширение для Chrome и Chromium, которое отслеживает новые сообщения в выбранных темах форума 4PDA и собирает их в аккуратный Markdown.

Основной сценарий — добавить интересующие темы, периодически проверять количество новых сообщений, а затем собрать нужные посты в один файл. Markdown можно читать отдельно, хранить как архив или передать ChatGPT либо другой LLM для краткого пересказа и анализа длинного обсуждения.

AI в расширение не встроен: Tracker только загружает страницы форума, извлекает сообщения и готовит Markdown. Анализ выполняется отдельно выбранным пользователем инструментом. Расширение работает локально, без собственного сервера, и использует авторизованную сессию 4PDA в браузере.

## Возможности

- отслеживание нескольких тем 4PDA;
- проверка количества новых сообщений сразу во всех темах без создания сборок;
- отдельный показ общего числа несобранных постов и числа постов после предыдущей проверки;
- сбор новых сообщений из одной темы или сразу из всех тем;
- автоматический обход нескольких страниц темы;
- локальная история сборок;
- копирование сборки в буфер обмена и скачивание файла `.md`;
- ручная отметка сборки **Разобрано**, которая сохраняется между запусками;
- ручная сортировка тем перетаскиванием за handle;
- использование выбранного порядка при общей проверке и сборе;
- открытие темы, сброс её точки отслеживания и удаление из списка.

## Что попадает в Markdown

Для сборки сохраняются название и адрес темы, время создания и количество новых постов. Для каждого сообщения экспортируются ID, автор, исходные дата и время, permalink и текст.

Парсер также:

- сохраняет связи с цитируемыми сообщениями и авторами, когда они явно присутствуют в разметке 4PDA;
- поддерживает несколько цитат в одном сообщении;
- удаляет содержимое цитат, оставляя на их месте короткие маркеры связи;
- сохраняет полезные ссылки;
- добавляет содержательные изображения и вложения как ссылки;
- отбрасывает служебные иконки, подписи редактирования и другой распознанный интерфейсный мусор 4PDA;
- исключает первый пост темы, обычно содержащий закреплённую шапку, из обычных сборок.

## Установка

Расширение не требует сборки.

1. Скачайте или клонируйте проект.
2. Откройте `chrome://extensions`.
3. Включите **Режим разработчика**.
4. Нажмите **Загрузить распакованное расширение**.
5. Выберите папку проекта, в которой находится `manifest.json`.

Перед использованием авторизуйтесь на 4PDA в этом же браузере. Минимальная поддерживаемая версия Chrome — 110.

## Первый запуск и добавление темы

1. Откройте любую страницу нужной темы 4PDA.
2. Откройте popup расширения.
3. Нажмите **Добавить текущую тему**.
4. Дождитесь сообщения об успешном добавлении.

При добавлении старые сообщения темы не импортируются. Расширение находит текущий последний пост и использует его как начальную точку: в последующие сборки попадут только более новые сообщения.

Повторите эти действия для остальных интересующих тем.

## Проверка и сбор

### Проверить новое

Кнопка **Проверить новое** проверяет все отслеживаемые темы и показывает, сколько сообщений ожидает сборки. Она ничего не добавляет в историю, не сохраняет найденные посты и не считает их собранными.

Результат `14 (+6)` означает, что после последней сборки накопилось 14 сообщений, из которых 6 появились после предыдущей проверки. Поэтому последовательность результатов может выглядеть так:

```text
8 (+8)
14 (+6)
14 (+0)
```

Последняя строка означает, что несобранных сообщений всё ещё 14, но после предыдущей проверки новых не появилось.

### Собрать всё

Кнопка **Собрать всё** последовательно собирает новые сообщения из всех отслеживаемых тем в заданном пользователем порядке. Для каждой темы с новыми сообщениями создаётся отдельная сборка. Если в теме ничего нового нет, пустая сборка не создаётся.

Ошибка одной темы отображается отдельно и не отменяет уже успешно обработанные темы.

### Собрать одну тему

Для одиночного сбора доступны два способа:

- открыть нужную тему и нажать **Собрать текущую тему** в popup;
- открыть страницу **Темы и история** и нажать **Собрать** в карточке темы.

Точка отслеживания обновляется только после успешного полного обхода темы. При ошибке незавершённый результат не считается собранным.

## Темы и история

Страница **Темы и история** открывается из popup. Здесь можно:

- изменить порядок тем, перетаскивая карточки за handle `⋮⋮`;
- собрать одну выбранную тему;
- открыть тему на 4PDA;
- сбросить точку отслеживания;
- удалить тему из списка;
- скопировать или скачать сохранённую сборку;
- вручную отметить сборку как **Разобрано**;
- скачать резервную копию локальных данных в JSON или восстановить её из файла.

Сброс переносит начальную точку на последний текущий пост темы. Уже сохранённая история не удаляется, но накопившиеся до сброса сообщения собраны не будут.

Отметка **Разобрано** служит только локальным напоминанием. Она не отправляет данные в ChatGPT, не меняет содержимое сборки и не скрывает её из истории.

## Хранение данных и приватность

Темы, собранные посты, сборки, отметки **Разобрано** и пользовательский порядок тем хранятся локально в IndexedDB профиля браузера.

Удаление расширения из Chrome может удалить его локальную IndexedDB. Если историю нужно сохранить перед удалением или переустановкой, сначала скачайте резервную копию на странице **Темы и история**.

У проекта нет AI, API для анализа или собственного облачного сервера. Расширение обращается к 4PDA через текущую браузерную сессию, но само никуда не отправляет подготовленный Markdown. Пользователь вручную копирует его или скачивает как файл и сам выбирает, где использовать дальше.

## Ограничения

- расширение рассчитано на ручной запуск и не ведёт постоянный фоновый мониторинг;
- работа парсера зависит от HTML-разметки 4PDA, поэтому изменения форума могут потребовать обновления расширения;
- CAPTCHA, завершившаяся сессия или страница входа могут прервать проверку или сбор;
- после принудительного завершения браузера или service worker незавершённую операцию нужно запустить повторно;
- старые сообщения не импортируются автоматически при первом добавлении темы;
- Tracker не анализирует содержание постов и не создаёт резюме самостоятельно.

## Структура проекта

- `manifest.json` — описание Manifest V3, разрешения и точки входа;
- `background.js` — управление ручными проверками и сбором;
- `crawler.js` — обход нужных страниц темы;
- `parser.js` — извлечение постов, цитат, ссылок, изображений и вложений из HTML;
- `markdown.js` — формирование Markdown;
- `common.js` — локальное хранение данных и общий порядок тем;
- `popup.html`, `popup.js` — основной popup и результаты операций;
- `options.html`, `options.js` — страница тем и истории;
- `styles.css` — общие стили интерфейса;
- `tests/` — браузерные и интеграционные тесты.

## Тесты

Для автоматического запуска нужны Python 3, пакет Playwright, Chrome и Chromium для Playwright.

Браузерные тесты парсера, crawler, Markdown, сортировки и IndexedDB:

```powershell
python tests/run.py
```

Интеграционные тесты настоящего MV3-расширения во временном профиле Chromium:

```powershell
python tests/extension.py
```

Интеграционный набор подменяет страницы форума локальными HTML-ответами и не использует пользовательский профиль.
