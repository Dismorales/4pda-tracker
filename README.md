# 4PDA Tracker

**Текущая версия: 0.3.10**

4PDA Tracker — локальное расширение для Chrome и Chromium, которое помогает вручную собирать новые сообщения из выбранных тем форума 4PDA. Оно запоминает последний обработанный пост, поэтому пользователю не нужно каждый раз перечитывать тему целиком.

Расширение работает без собственного сервера и использует текущую браузерную сессию 4PDA. Проверка запускается только пользователем: постоянного фонового мониторинга и автоматической проверки по расписанию нет. Темы, посты и история сборок хранятся локально в IndexedDB браузера.

Результат можно скопировать или скачать в Markdown. Такой файл удобно читать отдельно, хранить в заметках или передавать LLM для анализа, поиска решений и суммаризации обсуждения.

## Возможности

- отслеживание нескольких тем 4PDA;
- запоминание последнего обработанного post ID для каждой темы;
- автоматический обход страниц от сохранённой точки до текущего конца темы;
- исключение первого поста темы — закреплённой шапки;
- сохранение ID, автора, времени, permalink и текста сообщения;
- удаление содержимого цитат с сохранением связи с исходным постом и автором;
- поддержка нескольких цитат в одном сообщении;
- сохранение содержательных ссылок;
- inline-экспорт изображений с сохранением их позиции в тексте;
- сохранение вложений, которые не представлены inline;
- локальная история сборок;
- копирование и скачивание сборок в Markdown;
- атомарное сохранение постов, сборки и новой точки отслеживания только после полного успешного обхода.

## Установка

Расширение не требует сборки.

1. Скачайте или клонируйте репозиторий.
2. Откройте `chrome://extensions` в Chrome или Chromium.
3. Включите **Режим разработчика**.
4. Нажмите **Загрузить распакованное расширение**.
5. Выберите корневую папку проекта, в которой находится `manifest.json`.

Минимальная поддерживаемая версия Chrome — 110.

Чтобы применить обновление исходников, откройте `chrome://extensions` и нажмите кнопку обновления на карточке расширения. Не удаляйте установленное расширение, если хотите сохранить его локальную историю.

## Использование

### Добавление темы

1. Авторизуйтесь на 4PDA в браузере.
2. Откройте любую страницу нужной темы, например:

   ```text
   https://4pda.to/forum/index.php?showtopic=1109483&st=10440
   ```

3. Откройте popup расширения и нажмите **Добавить текущую тему**.
4. Дождитесь сообщения об успешной установке точки отслеживания.

При первом добавлении расширение находит самый свежий обычный пост и сохраняет его ID как стартовую точку. Старые сообщения автоматически не импортируются. Новая сборка начнётся со следующего опубликованного поста.

### Сбор новых сообщений

Проверку можно запустить двумя способами:

- открыть страницу отслеживаемой темы и нажать **Собрать новое** в popup;
- открыть **Темы и история** и нажать **Проверить** рядом с нужной темой.

Расширение создаёт одну неактивную служебную вкладку, определяет последнюю страницу темы и последовательно собирает все сообщения после сохранённого post ID. Popup или страницу истории можно закрыть во время работы.

После успешного обхода создаётся одна сборка, а точка отслеживания перемещается на последний собранный пост. Если загрузка или разбор страницы завершились ошибкой, точка не обновляется и повторная проверка остаётся безопасной.

Если новых сообщений нет, пустая сборка не создаётся. Обновляется только время успешной проверки.

### История и экспорт

Страница **Темы и история** показывает отслеживаемые темы, последний обработанный post ID, время последней успешной проверки и сохранённые сборки.

Сборку можно:

- скопировать в буфер обмена;
- скачать как файл `.md`.

Цитируемый текст в Markdown заменяется коротким маркером, например:

```md
**Ответ на:** пост #145041218, kumar03

[ЦИТАТА ИЗ ПОСТА #145041218, АВТОР kumar03, УБРАНА]

Текст нового сообщения…
```

### Сброс точки отслеживания

Кнопка **Сбросить точку отслеживания** заново находит последний текущий пост темы и делает его новой стартовой точкой. Она полезна, если нужно пропустить уже накопившиеся непрочитанные сообщения и продолжить отслеживание с текущего момента.

Сброс не удаляет существующие посты и сборки. Сообщения между прежней и новой точками после сброса собраны не будут, поэтому расширение запрашивает подтверждение.

## Хранение данных и приватность

Данные остаются в профиле браузера в IndexedDB с хранилищами `topics`, `posts` и `batches`. Расширение не требует отдельного логина или пароля и не отправляет собранную историю на собственный сервер.

Для загрузки страниц используются разрешения на `https://4pda.to/*` и `https://4pda.ru/*` и существующая сессия пользователя в браузере. Экспортируемые Markdown-файлы создаются локально.

## Структура проекта

- `manifest.json` — Manifest V3, разрешения, popup, options page и service worker;
- `background.js` — управление ручной задачей сбора и служебной вкладкой;
- `crawler.js` — обход страниц темы, фильтрация по post ID и сортировка результата;
- `parser.js` — разбор HTML страницы 4PDA: посты, даты, цитаты, ссылки, изображения и вложения;
- `common.js` — работа с IndexedDB и атомарное сохранение результата;
- `markdown.js` — формирование Markdown и имени экспортируемого файла;
- `popup.html`, `popup.js` — основной интерфейс расширения и статус текущей задачи;
- `options.html`, `options.js` — список тем, история сборок, проверка и сброс точки;
- `render-utils.js` — безопасное обновление списков карточек в DOM;
- `styles.css` — общие стили popup и страницы истории;
- `tests/run.html`, `tests/browser.js` — браузерные тесты парсера, обхода, Markdown и IndexedDB;
- `tests/run.py` — запуск браузерных тестов в установленном Chrome;
- `tests/extension.py` — интеграционные тесты настоящего MV3-расширения на локальных HTML-ответах.

В проекте нет этапа сборки и runtime-зависимостей: Chrome загружает исходные HTML, CSS и JavaScript напрямую.

## Разработка и тесты

Для автоматического запуска тестов нужны Python 3, пакет Playwright, установленный Chrome и Chromium для Playwright.

При необходимости подготовьте окружение:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install playwright
python -m playwright install chromium
```

Запуск DOM-тестов парсера, crawler, Markdown и IndexedDB:

```powershell
python tests/run.py
```

Ожидаемый итог:

```text
DONE: 18/18 passed
```

Запуск интеграционных тестов расширения Manifest V3:

```powershell
python tests/extension.py
```

Интеграционный тест создаёт временный профиль Chromium, загружает в него текущее расширение и подменяет страницы форума локальными HTML-ответами. Он не использует пользовательский профиль и не обращается к живой теме 4PDA.

Тесты также можно открыть вручную: загрузите `tests/run.html` как локальный файл в Chrome и проверьте результат на странице.

## Ограничения

- разметка 4PDA может меняться; неизвестная разметка, CAPTCHA или страница входа остановят сбор с ошибкой;
- после принудительного завершения Chrome или service worker автоматического продолжения нет — проверку нужно запустить снова;
- дата сохраняется в исходном виде; ISO формируется только при наличии явного часового пояса в HTML;
- расширение не импортирует старую историю темы при первом добавлении;
- постоянного мониторинга и уведомлений о новых сообщениях нет.
